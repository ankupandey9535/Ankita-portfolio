# Ankita Pandey — 3D Content Specialist Portfolio

A modern, high-impact 3D Creator style portfolio built for **Ankita Pandey**, Content Management Specialist (AEM, SharePoint, Contentful, SEO, & Governance).

## 🚀 Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & RemixIcon
- **Build Tool**: Vite

## 📁 Project Structure

## 🛠️ Local Setup & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ankupandey9535/Ankita-portfolio.git
   cd Ankita-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local dev server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
